- **Mobile First**: 64px mobile header, slide-out drawer navigation, 2x2 mobile stats strip, horizontal momentum scrolling filter bars, and touch targets $\ge 44\text{px}$.

## 🚀 Local Development

No heavy build tools or npm dependencies required — built with standard Vanilla ES6 modules:

```bash
# Clone the repository
git clone https://github.com/RVAKR/rvakr.github.io.git
cd rvakr.github.io

# Start a local web server (Python 3)
python -m http.server 8080 --bind 127.0.0.1

# Or with Node.js npx
npx serve .

# Open in your browser
start http://localhost:8080
```

## 📦 GitHub Pages Deployment

The repository deploys automatically to GitHub Pages:

1. Static files are served directly with [`.nojekyll`](.nojekyll) enabled.
2. Custom domain mapped via [`CNAME`](CNAME) to `rvakr.boreddy.com`.
3. To deploy updates:
   ```bash
   git add -A
   git commit -m "Deploy updates"
   git push origin master
   ```
